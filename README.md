# SCT_WD_2 — Chrono

A responsive React stopwatch for measuring time intervals and recording lap splits.

## Features

- Start, pause, and resume with a running clock that stays accurate while the tab is in the background
- Reset the clock and clear every lap
- Save lap splits and the total time at each mark
- Highlight the fastest and slowest splits once two or more laps differ
- Keyboard shortcuts: Space to start or pause, L to lap, R to reset
- Layout that stacks on phones and places the lap list beside the dial on wider screens

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints, usually `http://localhost:5173`.

## Build

```bash
npm run build
npm run preview
```
